## Q1 — Does the boundary-condition reading change P4's parity constraint? Yes; it dissolves for scalar/topological data, relocates for the phase.

P4's exclusion (Branch A + gauged orbifold, per AC's broadcast): the six lowest photon modes on S³ are the n=2 left- and right-invariant 1-forms; the antipodal map is +1 on them and C is −1, so each is CPN-odd; on a gauged Z₂ orbifold with fixed locus N=0, odd fields must vanish there → the one-photon seed is excluded.

The recast replaces "a field resident on the fixed locus" with "a boundary condition on it." The parity computation for a boundary datum is a *different* computation, and the answer depends on the datum's type:

- **Ω (conformal factor):** a positive real scalar (here ≈10⁶¹). The antipodal map acts trivially on a uniform scalar; C carries no action on a neutral scale; N-reversal does not flip a magnitude. **Z₂-even. Passes the fixed locus untouched.**

- **[g] (conformal class):** the parent end-state is de Sitter, maximally symmetric; its conformal class is CPN-invariant. **Invariant.**
- **U(1) quantum phase:** this is the one datum that carries the photon's charge. The photon is C-odd (C|γ⟩ = −|γ⟩); §5 establishes only *conformal* invariance of the phase, which is not CPN-invariance. **The phase inherits C-oddness; for it the exclusion is not dissolved but relocated** onto the phase datum.

**Answer.** The recast dissolves the exclusion branch for {Ω, [S³], [g]} and relocates it for {phase}. It dissolves rather than merely relocates *for those data* because P4's excluded object — the C-odd vector mode — is not any of them; it is a fourth thing (the photon field) that the boundary-data reading says does not cross.
