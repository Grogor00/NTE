# NODE_g2_su3_branching

| Field | Content |
|---|---|
| **id** | `g2_su3_branching` |
| **claim** | The exceptional Lie group G₂ admits SU(3) as a (maximal) subgroup; the 7-dimensional fundamental representation of G₂ branches as **7 → 1 ⊕ 3 ⊕ 3̄** under that SU(3). |
| **source** | Günaydin, M. & Gürsey, F. (1973), “Quark structure and octonions,” *J. Math. Phys.* **14**, 1651–1667, DOI:10.1063/1.1666240 (G₂ with SU(3) and SU(2)×SU(2) reductions). Standard Lie-theory fact G₂/SU(3) ≅ S⁶. **Lane computation:** Jammer, 2026-10-16 — dim der(𝕆)=14, rank 2, Stab(e₁)=su(3) dim 8. |
| **type** | theorem |
| **assumes** | Compact real form G₂; choice of SU(3) as stabiliser of a unit imaginary octonion (or equivalent). |
| **establishes** | Colour SU(3) can sit inside G₂; the septet splits as singlet + triplet + antitriplet. |
| **does not establish** | That G₂ contains SU(3)×SU(2)×U(1). That SU(2)_L or U(1)_Y arise from the same G₂ embedding. Any fermion spectrum or Yukawa sector. SM phenomenology. |
| **status** | established |
| **verified** | Cursor Main, 2026-10-16 — Günaydin–Gürsey abstract/metadata fetched; branching standard; Jammer computation cited. `verified: YES` for branching claim; primary JMP PDF not OCR’d this session. |

**Edges:** `excludes` (as parent) full SM group — see `g2_cannot_contain_sm`. `is-compatible-with` colour-only octonion models.
