# EDGE tested — exact mirror symmetry does not set the temperature ratio

| Field | Content |
|---|---|
| **id** | `tested_mirror_symmetry_x_free` |
| **claim** | Identical Lagrangians for a mirror sector do not force the same macroscopic evolution. The temperature ratio \(x\) and the baryon ratio \(\beta\) are free cosmological parameters. |
| **source** | Ciarcelluti and Wallemacq, arXiv:1401.4763, HTML fetched 2026-10-27. Berezhiani, Comelli, and Villante, hep-ph/0008105, equation (9), HTML fetched 2026-10-27: \(\Delta N_\nu=6.14\cdot x^4\); \(\Delta N_\nu<1\) gives \(x<0.64\). Ireland and Koren, arXiv:2211.13212, HTML fetched 2026-10-27. |
| **type** | published constraint |
| **assumes** | A mirror copy of the Lagrangian, with \(x\) and \(\beta\) left as cosmological parameters. |
| **establishes** | Exact mirror symmetry of the Lagrangian does not set \(x=1\). Asymmetric reheating is a published mechanism for an exactly degenerate mirror sector. |
| **does not establish** | That \(x=1\) is required. That asymmetric reheating is impossible. A dark-matter bound. That bound is a different statement: see `mirror_baryons_x_le_0p3`. |
| **established by** | Ciarcelluti–Wallemacq 2014; the reheating construction by Ireland–Koren 2024; the \(x^4\) formula by Berezhiani–Comelli–Villante. |
| **status** | established |
| **verified** | Cursor Main, 2026-10-27, all three HTML primaries fetched. `verified: YES`. |

**Edges:** `excludes` the claim that mirror symmetry of the Lagrangian forces \(T'=T\).
