## 3. Direct answer (ranked)

**If the goal is repair NTE into a coherent whole:**

1. **Most likely true flaw + best repair economy:** **Z3** → **GO-P03** (or even FS3 / P04-only). Works. Repairs by cutting the false CDM identification. Matches Part 3’s own OPEN + withdrawn κ=Ω_DM.  
2. **Must-do geometric repair regardless of CDM:** **Z4** → **GO-O1-FL2**. Works as gravity completion; repairs O1; does not by itself restore DM ID.  
3. **Only path that rehabilitates bridge-as-CDM:** assume **Z6 (Z1+Z2)** → **GO-O1-FL2 + GO-FC2** together. Either alone is incomplete.  
4. **GO-FC2 alone** repairs only if the flaw is narrowly Z2 — and still fails Bullet.  
5. **Amplifier restore** — does **not** repair under any cold/location flaw.

**If “both work and repair” means a *single* GO that fully fixes CDM-as-bridge:** **none.** No single GO path does R2-complete. The conjunct is **FL2+FC2**, which admits NTE was flawed in **two** places (location truncation + twin-temperature bind).

**If “both work and repair” means one GO that is sufficient for a consistent NTE:** **GO-P03** (under Z3) or **GO-O1-FL2** (under Z4, leaving CDM to P04/P03).
