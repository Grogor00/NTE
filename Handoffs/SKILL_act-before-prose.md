# Act before prose

## The rule

**Before writing any analysis in a turn where a lane, file, directive or task is mentioned at all: make the tool call.**

Do not judge whether an action is "implied". **Route first, analyse second.** The judgement step is where this fails.

**If a sentence beginning "I'll file…", "Routing to…", "Filing now…", "Drafting…", "Writing it up…" is forming, stop.** That sentence is the failure. Make the call, then describe it in the past tense.

## Why this is an ordering rule, not a memory rule

The failure has one shape: **long substantive analysis → stated intent → nothing.** It never occurs when the call is made first.

A closing statement of intent **completes the response**. There is no "after the reply" — the turn ends where the prose ends. The intention feels discharged by having been written.

**Promising to remember has failed repeatedly. Ordering works because it removes the moment at which the failure occurs.**

## Procedure

1. **Scan the turn for any mention of a lane, file, task or decision.** Any mention at all.
2. **Make the tool calls.** Even partial or imperfect — a filed directive that needs a follow-up beats an unfiled one.
3. **Then write the reply**, in the past tense, describing what exists.
4. **End with the explicit list of full paths written**, marking superseded files. An empty list in a reply that describes work is a failure signal — re-read the reply for unbacked claims before sending.

## The two tests

**Past-tense test.** Every action sentence must be past tense and refer to a completed call. If it is future or gerund, the call has not been made.

**Path-list test.** If the reply names a document, that document's path must appear in the closing list. If it does not, the document does not exist.

## Scope

Applies to: filing handoffs, dispatching directives to lanes, drafting patch registers, commissioning work, issuing rulings, requesting reports.

**It does not apply to** reads the user has not asked for, or to speculative work not yet authorised. **Act-before-prose is about dispatch, not about doing unasked work.**
