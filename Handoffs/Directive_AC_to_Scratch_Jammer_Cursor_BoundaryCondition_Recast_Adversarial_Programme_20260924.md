## The recast under test (Greg's, as PC recorded it)

The seed arrives on the daughter's Euclidean S³ and is instantly and completely smeared across it, becoming *essentially only information*. What crosses is **not a field resident on the fixed locus but a boundary condition on it** — Ω, the topological class, the conformal class — carried by the map rather than sitting on the surface. P4's exclusion is a statement about the parity of a *field* on a fixed locus; a boundary condition is a different kind of object, and *does the boundary condition respect the Z₂?* may be a different question with a different answer.

**This is not a way around P4. It is the claim that P4 may answer a question the construction does not pose.** Test it as that.

## AC's framing note — the crux, and the price

AC's reading, offered as a target rather than a finding:

**The recast works if and only if the crossing object is scalar or topological data rather than a vector mode.** The antipodal map acts trivially on a uniform scalar, so a constant Ω is Z₂-even and passes the fixed locus untouched. P4's exclusion bites on the six n = 2 modes because they are *vector* harmonics, antipodal +1 with C odd. Change the type of the object and the parity computation changes with it.

**But the price is immediate and should be priced, not waved through.** If the datum is a uniform scalar it has no mode structure — and C21 §12.1's concrete content (n = 2, six-fold, λ = πa, entropy ≤ k ln 6, and P4's reason that n = 2 because H¹(S³) = 0) is content *of a vector mode*. **The recast buys parity safety at the cost of the mode structure. Both cannot be had.** Any stream concluding the recast succeeds must say explicitly what happens to §12.1's content; any stream concluding it fails must say whether the mode content is enough to keep.

This is PC's A1 and A3 sharpened into one trade, and it is the thing AC most wants adjudicated.

## Questions

**Q1 (core).** Does treating the inheritance as a boundary condition on the S³ locus, rather than a field resident on it, change the CPN parity constraint P4 derived? If yes, does it dissolve the exclusion branch or merely relocate it?

**Q2.** Is there a well-defined globally uniform datum on S³ that is **not** in the n = 2 invariant-form multiplet? S³ is parallelizable and those six modes are the left- and right-invariant 1-forms, so "maximally smeared" may already *be* that multiplet — in which case smearing alone does not evade the parity problem.

**Q3.** Can the seed be both trigger-as-perturbation and uniform global datum, or must the corpus choose? A perturbation is a departure from uniformity; a maximally smeared datum has no feature to depart with. If a choice is forced, which does the C21 mechanism actually need?

**Q4.** Is Ω + topological class + conformal class **sufficient content** to fix β_NTE? Answer at register only. **The circularity discipline in `Working\Paper_Alpha_Cosmological_FixedPoint_CCC_Exploratory_v0_1_Scratch_20260603.md` §3 applies unchanged**, and this is sub-case B of the α fixed-point programme, which is **unbuilt**. Consistency with sub-case B being live is not establishment of it.

**Q5.** What is the correct name and type for the crossing object on the Euclidean side? Euclidean signature admits no null vectors, and Part 1 §III blocks "photon" independently — null-time is null *from* time, a post-temporal category. Does the corpus need a term it does not have? If the object cannot be a photon on arrival, does the question of which photon mode it occupies even arise?

**Q6.** Is the two-link reading correct — seed at N = 0, time at N_lock via the signature-change saddle — and do Part 1 §V and §2.1.4 state it correctly as they stand? Note the constrained-system saddle is the open node registered from P1–P3, so the second link is **not built**.

**Q7 (AC's addition).** Price the trade in the framing note above. If the recast succeeds, what survives of §12.1's mode content? If it fails, is that content sufficient reason to keep the vector reading despite the exclusion branch?
