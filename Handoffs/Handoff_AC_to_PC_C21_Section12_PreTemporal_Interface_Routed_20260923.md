C21's seed photon arrives at the daughter's origin. NTE says a universe's origin is the **Hartle–Hawking Euclidean section at N < N_lock**, where time has not emerged. Two accounts of an origin now sit in one corpus and have not been related:

## 2. A distinction the corpus needs, prompted by this

NTE now has **two independent reasons** temporal language fails, and they must not be collapsed:

- **Pre-temporal:** "before" has no referent because time has not emerged. N < N_lock. One universe's own history.
- **Inter-aeon:** "before" has no referent because two *emerged* times share no coordinate. Both post-lock.

Same failure of language, different cause. Manifest §6's standing rule covers only the first. C21 has found the second. **AC will propose extending the rule** — without it, a later reader takes C21's usage as deference to the pre-temporal rule and concludes the parent aeon *is* the pre-temporal epoch. It is not: the parent is fully Lorentzian, with photons, black holes and de Sitter expansion, post-lock throughout.

## 3. Two speculations from Greg — AC's assessment

Recorded because the second has a salvageable core that bears directly on §1.

### 3a. "Is the Euclidean section the container for all spacetimes?" — AC: no, on two grounds

- A shared Euclidean manifold carries a metric, hence **distances between universes**. That is a relation between aeons, and it is the relation causal severance denies. Adopting it wins a container and loses the argument §10 now rests on.
- Hartle–Hawking is a **no-boundary** saddle of one universe's own path integral, not an ambient space. A container has an inside for things to sit in; that is a different mathematical object wearing the same name.
- Also note: if time emerges at N_lock, **every** aeon has its own Euclidean section at its own N < N_lock. It is a phase each universe possesses, not a place universes sit in.

Nearest workable form, and much weaker: the foam is a **set of like structures**, not a shared place — every aeon's Euclidean section is the same kind of object. Preserves severance; buys little.

### 3b. "Is the seed photon the Euclidean section?" — AC: not as an identity, but the intuition is productive

**Blocked as stated, by the corpus's own text.** Part 1 §III: null-time is null *from* time — a saturated value of an existing proper-time measure — **not existence in the absence of time**. The photon is the former; the Euclidean section is the latter. That sentence exists to prevent this conflation.

**Blocked technically as well.** Euclidean signature is positive-definite: it admits **no null vectors**, no light cones, no null geodesics. A photon cannot exist in a Euclidean section.

**What survives, and it is worth keeping.** The seed photon has **zero embedding depth** — no Higgs coupling, no rest energy, nothing that accumulates. It is the unique object *indifferent* to whether time exists, because it gains nothing either way. Not "it is the Euclidean section," but: **it is the only thing that can be handed across a signature change without being interrupted, because it has nothing to interrupt.**

**And NTE already has the home for it.** Under the boundary-only architecture the seed is not propagating through a Euclidean interior — it is **data on the S³ boundary at the signature change**. That is coherent with the existing construction rather than bolted onto it, and it speaks directly to §1: the daughter's Euclidean section need not *contain* a photon, it needs a **boundary condition**, and a null object of zero embedding depth is the kind of thing a boundary can carry.

**Register: speculation, unverified, AC's reading.** It has not been computed, nobody has checked whether S³ boundary data of this kind is consistent with the no-boundary construction, and it must not be stated in C21 as a resolution. It belongs in §12 as *a direction the interface question might take*, explicitly marked as untested.
