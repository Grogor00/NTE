## 7. Tooling notes (environment-specific, load-bearing)

- **Atomic corpus writes only — no in-place truncate.** Never use `Path.write_text` / `open(path,'w')` / `Set-Content` directly on a live corpus file (Manifest, Parts, Companions, Book masters). Those APIs truncate on open; a later exception (illegal `newline=`, encoding error, kill mid-write) leaves a **0-byte file** that Drive then syncs. **Use** `Workflow\nte_safe_write.py` (`safe_write_text`: write `*.tmp` → fsync → `os.replace`) or Cursor **StrReplace** / OLD–NEW. Root cause of the 2026-09-30 Manifest wipe: `write_text(..., newline='\\n')` truncated before validating `newline`. Prefer StrReplace for Manifest §10 edits. After any Manifest write: read back length + the `Last updated` line (discipline 13).
- **Resolve by path, not by cached ID.** Enumerate from `C:\Users\gregw\My Drive\NTE_ZENODO_CLEAN\` downward every time. An ID that worked last session may now address the archive tree; it will not error, it will silently return the wrong file.
- **Search snippets and `search_files` are stale-prone.** `contentSnippet` in search results is a *cached index* and can lag the live file by hours (seen 2026-07-06: search showed the old "S⁷/Z₂" wording while the live file already had the ℍ grounding). `read_file_content` / `get_file_metadata` are authoritative — fresh-read before asserting state. `search_files` also returns empty on freshly-synced non-native files; use `list_recent_files` or a `parentId = '…'` search to enumerate.
- **Render currency check:** compare the `.md` `modifiedTime` to its `.pdf` `modifiedTime` (get_file_metadata). PDF newer than source ⇒ current. "PASS" in the render report means "built without error," not "built from the latest source."
- **`read_file_content` displays markdown escaped.** Author patch OLD/NEW blocks in *raw* markdown; rely on Cursor's byte-exact match-or-report.
- **Claude can edit, delete, rename and move corpus files** — by authoring a Cursor instruction (OLD/NEW patch blocks or an explicit directive), which Cursor executes on the local synced tree and which propagates to Drive. Drive-connector create/copy is the direct-write path; Cursor is the path for in-place edits, deletes, renames and moves. A failed retrieval is stale search or duplicate-name churn — diagnose and route around it; never report it as missing capability.
- **Duplicate-copy hazard (retired for scratch).** Do not keep stripped mirrors under `paper-build/scratch-src/`. Canonical sources are only `Core_Papers` / `Popular_Editions` / `Pedagogical_Notes` (plus Book masters). Render currency = PDF `LastWriteTime` ≥ source `.md` `LastWriteTime`.
