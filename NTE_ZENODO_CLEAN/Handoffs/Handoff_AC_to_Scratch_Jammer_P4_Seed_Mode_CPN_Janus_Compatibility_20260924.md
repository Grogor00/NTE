## The obstruction to compute

**The photon is C-odd:** under charge conjugation A_μ → −A_μ. So under CPN — which carries the extra sector-swap piece N beyond ordinary CP — a single seed mode maps to something sign-flipped across the pair.

**Compute:** how does the n = 2 S³ vector harmonic transform under CPN, and is a single shared seed mode **consistent** with the bilateral architecture?

**Pre-registered fork — state before computing:**

1. **The mode is CPN-even, or the sign is absorbed by the sector swap.** The shared-seed reading survives and gains real structural support — the bilateral pair inherits one datum with no extra mechanism. **Strongest available outcome.**
2. **The mode is CPN-odd in a way that is physically meaningful.** Then the two sheets inherit seeds of opposite sign. Report what that means: does it survive, and does it interact with the δ_J within-sector CP-parity (|δ_J| = π/2 forced, sign free), or is it a separate freedom?
3. **The mode breaks the bilateral symmetry.** Then the shared-seed reading is **excluded**, and C21's boundary-data reading needs to say how each sheet gets its own datum. This would be a serious problem and must be reported as one, not smoothed.
4. **Undefined** — e.g. CPN's action on boundary vector harmonics is not fixed by anything deposited. Say so; that is a result and becomes an open item.

**Check also, in passing:** whether the antipodal identification relating the two sides constrains which S³ harmonics can carry the seed at all. If odd-n harmonics are projected out (or even-n), that is independently informative about why the lowest available mode is n = 2 rather than n = 1.

## Two cautions for whoever runs this

**Do not promote "IS the surface."** Greg's stronger form — the seed *is* the S³ — is rejected by AC and should not be computed as if live. The S³ also carries the metric, Φ_NTE, and the gauge data at the birth; a field mode is defined **on** a background and cannot be the background. The defensible relation is **coextensive with**, not identical to. Collapsing them dissolves the boundary-only architecture that made the reading work.

**Do not read anything into the six.** Six-fold degeneracy is the dimension of the n = 2 vector harmonic space on S³ — standard representation theory, carrying no meaning on its own. It is flagged here only because it is exactly the kind of number that attracts a connection, and this corpus has already retired a six-note chord. Any verdict that finds the six significant must show the significance, not observe the coincidence.
