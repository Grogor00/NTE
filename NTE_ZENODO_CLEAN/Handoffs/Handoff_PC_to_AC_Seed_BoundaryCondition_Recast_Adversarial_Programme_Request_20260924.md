## 2. Greg's recast, stated as he put it

The photon leaves the parent, arrives on the daughter's Euclidean S³, and is **instantly and completely smeared across the entire surface** — becoming, in his words, *essentially only information*. That smearing is the transition that nucleates the conjugate pair. The seed is a trigger, and a trigger owes nothing to persistence: he had already observed, correctly, that "survives", "continues" and "persists" are temporal predicates with no referent at N < N_lock, so asking whether the seed endures is a question of the same class as asking what happened before.

**The operative move, in PC's words:** what crosses is not a *field resident on the fixed locus* but a **boundary condition on it** — Ω, the topological class, the conformal class, carried by the map rather than sitting on the surface.

**Why that could matter.** P4's exclusion is a statement about the parity of a field on a fixed locus. A boundary condition is a different kind of object, and the corresponding question — *does the boundary condition respect the Z₂?* — is a different question, possibly with a different answer. This is not a way around P4; it is a claim that P4 may be answering a question the construction does not pose.

## 3. PC's three amendments, for the streams to test alongside the recast

**A1 — the smearing intuition lands on the computed object, and therefore inherits its parity.** S³ is parallelizable, so it admits globally non-vanishing invariant vector fields, and per P4 the six n = 2 modes *are* the left- and right-invariant 1-forms. "Maximally smeared" is therefore not a vague picture — it is that multiplet. Which means smearing **by itself** does not evade the parity problem: those are exactly the modes evaluated as antipodal +1, C odd, hence CPN-odd on branch A. The recast only helps if the crossing object is genuinely *not* one of those modes.

**A2 — "photon" has no referent on the receiving side.** Euclidean signature is positive-definite: no null vectors, no light cones, no photons. Part 1 §III independently blocks it — null-time is null *from* time, a post-temporal category. So the object is a photon in the parent and is not a photon in the daughter's Euclidean section. This looks like naming, but it may be load-bearing: if the crossing object cannot be a photon on arrival, the question of *which photon mode it occupies* may not arise, which is close to the recast's own claim.

**A3 — "perturbation" and "completely smeared" pull against each other.** A perturbation is a departure from uniformity; a maximally smeared datum has no feature to depart with. It can set scale and conformal class; it cannot seed inhomogeneity. Greg used both framings and they are different jobs.

## 4. Two costs the recast carries, which the programme should price

**C1 — content sufficiency.** If the datum is featureless, §6 requires the fingerprint to carry enough to set the daughter's constants. Ω plus topology plus a conformal class — is that enough to fix β_NTE? **That is precisely sub-case B of the α fixed-point programme, and it is unbuilt.** The recast is *consistent with* sub-case B being live; it does not establish it. Any stream tempted to bank this should note that the circularity discipline in `Working\Paper_Alpha_Cosmological_FixedPoint_CCC_Exploratory_v0_1_Scratch_20260603.md` §3 applies unchanged.

**C2 — the chain has two links, not one.** The seed sits at N = 0; time appears at N_lock, at the signature-change saddle. So the seed does not kickstart time — it sets the condition from which the construction whose saddle produces time proceeds. Greg's phrasing compresses the two, and the compressed form would read as a stronger claim than the corpus supports. Note also that the constrained-system saddle is itself the open node registered from P1–P3, so the second link is not built either.

## 5. The questions, for the adversarial programme

**Q1 — the core.** Does treating the inheritance as a boundary condition on the S³ locus, rather than a field resident on it, change the CPN parity constraint P4 derived? If yes, does it dissolve the exclusion branch or merely relocate it?

**Q2.** Is there a well-defined "globally uniform datum" on S³ that is *not* in the n = 2 invariant-form multiplet? If not, A1 stands and the recast requires the crossing object to be something other than a vector configuration.

**Q3.** Can the seed be both trigger-as-perturbation and uniform global datum, or must the corpus choose? If it must choose, which does the C21 mechanism actually need?

**Q4.** Is Ω + topological class + conformal class sufficient content to fix β_NTE? Answer at register, with the circularity discipline enforced.

**Q5.** What is the correct name and type for the crossing object on the Euclidean side? Does the corpus need a term it does not currently have?

**Q6.** Is C2's two-link reading correct, and do Part 1 §V and §2.1.4 state it correctly as they stand?
