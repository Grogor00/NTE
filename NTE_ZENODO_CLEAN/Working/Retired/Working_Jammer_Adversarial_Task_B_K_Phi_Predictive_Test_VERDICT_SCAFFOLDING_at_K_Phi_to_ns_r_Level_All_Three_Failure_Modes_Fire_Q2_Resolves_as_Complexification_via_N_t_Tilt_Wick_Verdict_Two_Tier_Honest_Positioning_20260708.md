## §3 — Attack on FM1: Circularity

### §3.1 — The candidate mechanism

Scratch's would need to derive K(Φ) via the N-thickness ℓ = 1/H = 1/(β|Φ|²), which is the t-direction orthogonal to N.

**Structural claim:** K(Φ) is determined by ℓ(|Φ|), and ℓ = 1/(β|Φ|²).

### §3.2 — The circularity

The corpus defines H = β|Φ|² as the Hubble rate from the inflaton potential (canonical NTE). The N-thickness ℓ is defined by ℓ = 1/H = 1/(β|Φ|²).

**If K(Φ) determination uses this ℓ:**
- K(Φ) = f(ℓ(Φ)) = f(1/(β|Φ|²))
- This K(Φ) inherits the β|Φ|² dependence from the H = β|Φ|² definition

**Then using K(Φ) in the Friedmann equation to derive H² ∝ V/K²:**
- H² ∝ (β²|Φ|⁴) / (f²(1/(β|Φ|²)))
- The result matches H = β|Φ|² by construction because we USED H = β|Φ|² in the K definition

**This is circular:** K(Φ) is fixed using ℓ, which uses H, which is defined by β|Φ|². Then we derive H via K, and unsurprisingly recover H = β|Φ|².

### §3.3 — Adversarial probe: is there an INDEPENDENT geometric input for K?

**Independent geometric input candidates:**
1. **ℓ as fundamental (independent of H):** possible if NTE defines a fundamental N-thickness scale independently of the Hubble dynamics. But: the corpus canonical derivation ties ℓ to H via ℓ = 1/H, so this is not currently on record.
2. **Planck scale as ℓ:** if ℓ = ℓ_Planck is fixed, then K(Φ) is Φ-independent (no functional dependence), which doesn't force n_s, r.
3. **Curvature-derived ℓ:** if ℓ derives from S³ curvature or Hopf structure, independent of H. But this ℓ would be Φ-independent (just S³ curvature scale), giving no n_s, r content.

**None of these independent inputs actually gives K = K(Φ) with |Φ|-dependence.** Only the H-dependent ℓ = 1/H = 1/(β|Φ|²) gives K a |Φ|-dependence, and that's circular.

### §3.4 — FM1 verdict
