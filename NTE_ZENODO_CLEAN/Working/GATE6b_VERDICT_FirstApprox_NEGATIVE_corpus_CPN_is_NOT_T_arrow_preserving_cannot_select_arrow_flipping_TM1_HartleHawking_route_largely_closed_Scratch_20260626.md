## The clash

| operation | orientation / arrow character | det |

| **S·U** (TM1 selector) | **arrow-reversing** — negates timelike axis (2,−1,−1); time-reversal-like | **−1** |

This is the same wall P4D already documented: generation-space discrete operations are *parallel*, not descended, from bilateral CPN.

## The only genuine T in the corpus is the wrong epoch

The corpus's sole time-reversal lives in **CPT = Θ∘CPN**, which is **emergent post-locking** — it exists only *after* time emerges. The generation mass texture is fixed in the pre-temporal/algebraic regime. A post-locking T cannot reach back to select a pre-temporal mixing structure. So even CPT does not supply the selector in the right epoch.

## Verdict

**First approximation: the Hartle–Hawking/CPN-selector version of the Gate-6 hypothesis is largely killed.**
- CPN is arrow-preserving and explicitly ≠ T; S·U is arrow-reversing. No match.
- The only corpus T (Θ in CPT) is emergent post-locking — wrong epoch for a pre-temporal texture.
- Consistent with the corpus's own P4D finding (generation Z₂ ≠ CPN; parallel-not-descended).

The Gate-6 *correspondence* stands as a true description (TM1 = the timelike branch), but the corpus's time/signature machinery does **not** provide a mechanism that *selects* it. **The full J₂⊂J₃ build is not warranted on the CPN premise** — going in blind would have hit this wall after far more work. The first-approximation discipline paid off.

It is the only part of the Gate-6 hypothesis still standing.
